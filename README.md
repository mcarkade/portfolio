# mcarkade

Abhinav Pullela's portfolio, built as one continuous scroll-driven film.

**Live:** https://mcarkade.vercel.app

![MCARKADE](public/og.jpg)

## What's in it

1. **Title sequence.** Frames of my projects flip through the letters of MCARKADE, then slam into a red block.
2. **The drone.** My F450 quadcopter assembles, comes apart as you scroll, and takes off.
3. **Vision and lock-on.** The drone flies its mission, then you fly it yourself while a counter-drone turret tries to hold it in the crosshair.
4. **Multiroads.** Cars from my browser racing game, ending on the McLaren MP4/5, which comes apart and launches down the road.
5. **Work, about and contact.**

Press `L` for the lights and `M` for sound.

## Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```
